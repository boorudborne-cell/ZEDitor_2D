# ZEDitor_2D
Современная разработка игр всё чаще требует гибких и доступных инструментов для создания уровней — особенно для начинающих разработчиков, студентов и независимых авторов. Целью данного проекта является создание редактора карт для двумерных платформеров, сочетающего простоту использования с достаточной функциональностью для реализации разнообразных игровых идей. Предполагается использовать популярный игровой движок Unity и язык C# для обеспечения стабильности, кроссплатформенности и удобства расширения. Редактор будет поддерживать визуальное редактирование, систему отмены действий, быстрый запуск тестов уровня и сохранение данных в открытом формате, что позволит пользователям эффективно экспериментировать и итерировать в процессе разработки.
